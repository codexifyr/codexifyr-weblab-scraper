Quick Start

  1. Run a full scan in Website Scraper.
  2. Open Validation Center and review anomalies.
  3. If needed, upload the scan to File Correction and repair only selected fields.
  4. Validate the corrected data again.
  5. Build the Full WordPress Migration ZIP.
  6. Install the Codexifyr WordPress Importer plugin once.
  7. Upload the migration ZIP inside WordPress → Codexifyr and run the import.

site-data.json

The master structured capture of the source website: products, variants, pages, blogs, categories, menus, SEO, branding and media references. Keep it as a backup.

migration-report.json

A diagnostic/report file with scan or repair information. It helps explain what Codexifyr captured and what may need review.

WordPress Migration ZIP

The WordPress-ready package. It contains a canonical site-data.json, report, generated theme ZIP and import instructions.

How Restart Recovery Works

Each scan has its own job workspace. Full scans save a URL checkpoint plus partial site data; repairs append successful field changes to a delta log. If Windows, the network, Chromium or Codexifyr stops, the Job History page restores the job as interrupted and offers Resume. Completed URLs are skipped instead of starting from zero.

Network/CAPTCHA behavior is conservative. CAPTCHA challenges must be solved manually in the visible browser. Permanent 404/410 URLs are skipped without wasting retries.

Important Limitations

Codexifyr captures public website content and reconstructs it for sites you own or are authorized to migrate. Highly proprietary page-builder behavior, licensed scripts/fonts, private store settings, payment/shipping configuration, complex third-party widgets and exact pixel-for-pixel theme internals may require manual WordPress work. Always test large imports on staging before replacing a live site.
