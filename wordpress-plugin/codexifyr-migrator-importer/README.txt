Codexifyr Website Migrator Importer
Version 3.0.0

Install this plugin once in WordPress, then upload Codexifyr migration ZIPs from WordPress Admin > Codexifyr.

Highlights
- Imports pages and blog posts in batches.
- Imports WooCommerce simple and variable products.
- Preserves product categories/tags, prices, stock, variation attributes and variation images.
- Sideloads media with source-URL de-duplication.
- Imports menus, site logo, favicon and common SEO plugin fields.
- Installs/activates the generated Codexifyr source theme included in the migration package.
- Progress is stored in WordPress, so clicking INSTALL/RESUME continues the existing job stage.
- Runs an expected-vs-imported verification summary after the final import stage.

For store migrations, install and activate WooCommerce first.
Always test large migrations on a staging site before replacing a production site.
